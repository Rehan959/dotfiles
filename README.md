# dotfiles

Personal configuration files for Linux setup.

## What's included

- **Neovim** — Editor config (LazyVim)
- **Hyprland** — Window manager
- **Waybar** — Status bar
- **Alacritty / Ghostty / Kitty / Foot** — Terminal configs
- **Tmux** — Terminal multiplexer
- **Starship** — Shell prompt
- **Opencode** — AI coding tool
- **Btop** — System monitor
- **Lazygit / Lazydocker** — Git and Docker TUIs
- **Walker** — App launcher
- **Fastfetch** — System info
- **Zed** — Editor
- **Shell configs** — zshrc, bashrc, bash_profile, profile
